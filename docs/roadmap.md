# Roadmap

This roadmap lists planned improvements only. It does not describe completed features unless they already exist in the codebase.

## Planned

- Web dashboard for local monitoring
- Better model evaluation with holdout datasets
- Docker support for development environments
- More camera backend options
- Face tracking metrics
- Encrypted local dataset option
- Performance benchmark script with hardware metadata
- Structured recognition event logging
- Config validation CLI command

## Not planned as default behavior

- Uploading face samples to a cloud service
- Committing real face samples or trained biometric artifacts
- Advertising authentication-grade security without additional controls

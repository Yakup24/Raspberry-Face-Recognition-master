# Roadmap

This roadmap lists planned improvements only. It does not claim completed features.

## Planned

- Encrypted local embedding store
- Liveness/anti-spoofing module
- Detector/backend selection from config
- Threshold calibration helper for local datasets
- Performance benchmark script with hardware metadata
- Structured recognition event logging
- Local dashboard for device-only monitoring
- Edge accelerator notes for Jetson/Coral-class devices
- Pluggable reviewed action adapters for notifications or hardware integrations
- Optional depth-estimation adapter with measured hardware notes
- Local VLM deployment guide for private Omni reasoning
- MQTT broker hardening guide for multi-node telemetry
- Config validation CLI command

## Not planned as default behavior

- Uploading frames, embeddings or labels to a cloud service
- Committing real face samples, FAISS indexes or trained biometric artifacts
- Advertising authentication-grade security without additional controls
- Executing model-generated code inside the runtime loop
- Claiming medical, stress, quantum, BCI, AGI or ASI behavior without real validated systems
